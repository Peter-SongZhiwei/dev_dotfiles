# @提醒功能 (@User) 规范

## 概述

本规范详细介绍如何在icenter页面中嵌入@提醒功能。

## @提醒功能机制

icenter使用特殊的链接标签来实现@提醒功能：

### @提醒功能HTML结构

```html
<a class="at-user" 
   contenteditable="false" 
   data-employeeid="10217503" 
   data-employeename="闫斌" 
   data-uuid="96a7fd65bd1144f5824566935b38b708" 
   href="/#/profile/10217503">闫斌10217503</a>
```

### @提醒功能特点

- **HTML标签**：使用`<a>`标签实现
- **CSS类**：`at-user` 标识为@用户功能
- **数据属性**：
  - `data-employeeid`：员工ID
  - `data-employeename`：员工姓名
  - `data-uuid`：唯一标识符
- **链接功能**：跳转到用户个人资料页面
- **显示格式**：姓名+员工号

### @提醒功能类型

- **任务分配**：分配任务给特定人员
- **内容审核**：提醒相关人员审核内容
- **协作通知**：通知团队成员关注特定内容
- **问题反馈**：@相关人员处理问题

## 创建流程

1. 需求分析 - 确定提醒的目的和内容
2. 人员信息确定 - 确定被提醒的人员，获取正确的员工信息
3. HTML内容构建 - 嵌入@提醒功能HTML结构
4. 页面创建 - 使用 `create_page_by_url_with_content`

## 注意事项

1. 用户信息准确：确保@提醒的用户信息准确，避免错误提醒
2. @提醒功能配置：正确配置用户信息和链接属性
