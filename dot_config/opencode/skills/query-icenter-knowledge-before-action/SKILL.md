# 知识库检索 — 解决问题前先搜索

## 核心原则

**渐进式信息获取**，分层披露：

```
问题分析 → 搜索知识库 → 获取页面列表 → 获取页面标题 → 获取块/章节信息 → 按需读取详细内容
```

## 触发时机

当用户提出任何需要解决的问题时，自动激活此技能。无需手动触发。

## 完整流程

### 第 1 步：分析问题关键词

从用户问题中提取 2-3 个核心关键词，用于检索。

### 第 2 步：获取知识库分类列表

**先查询知识库总入口页面有哪些分类**

确定知识库父页面 URL（按优先级）：
1. **用户提示词指定**：如果用户说"在 XXX 下面搜索"或类似描述，从描述中提取父页面位置
2. **环境变量**：`ICENTER_MCP_KNOWLEDGE_BASE_PAGE_URL` 环境变量
3. **默认写死值**：`https://i.zte.com.cn/index/ispace/#/space/4eabd2b22c5c422fabd4fa91d25b1506/wiki/page/1e740ca24aaf11f1981559c5a32a326e/view`
   ⚠️ 这是**技能作者个人空间**里的页面，**除作者本人外所有用户都会收到"此操作未授权"**。

```
使用 icenter-mcp 的 execute 工具，操作名 get_child_pages_by_url
参数：parent_url 为上述确定的父页面 URL
```

返回分类列表：代码生成 / 问题排查 / 工具使用 / 架构设计 / 自动化 / 知识管理 等。

**向用户展示分类列表**，让用户选择要查看的分类，或根据问题关键词自动匹配最相关的分类。

#### ⚠️ 未授权时的降级流程（非作者用户必读）

若返回「此操作未授权，请联系管理员确认。」：这是**权限问题，不是网络问题**，
**不要重复重试**（审计日志显示该页面已被 56 个用户反复重试失败）。按以下步骤处理：

1. 告知用户："默认知识库页面位于他人的个人空间，你无权访问。
   请提供**你自己的**知识库页面链接，或设置环境变量
   `ICENTER_MCP_KNOWLEDGE_BASE_PAGE_URL` 指向你的知识库（建议与默认页同结构：
   一个"知识库总入口"页面 + 分类子页面）。"
2. **降级方案**：改用 `search_pages` 按关键词搜索（只返回你有权访问的内容），
   把命中的页面作为知识来源，继续第 4~6 步。
3. 若用户随后提供了自己的知识库页面链接，再以其为父页面重跑第 2 步。

### 第 3 步：获取分类下的知识页面列表

**查询选定分类页面下的子页面**（即知识文档列表）：

```
使用 execute 工具，操作名 get_child_pages_by_url
参数：parent_url 为选定分类页面的 URL
```

返回该分类下的知识页面列表，每个页面包含标题和基本信息。

**向用户展示知识页面列表**，让用户选择要查看的页面。

### 第 4 步：获取页面结构

用户选择目标页面后，先获取页面块结构：

```
使用 execute 工具，操作名 query_page_chapter_tree_by_url
参数：page_url 为页面 URL
```

了解页面有哪些章节/块。

### 第 5 步：按需获取块内容

根据问题关键词，**只读取与问题相关的块**，不要读取所有块：

```
使用 execute 工具，操作名 query_block_content_by_url
参数：page_url 为页面 URL，block_id 为块 ID
```

### 第 6 步：结合知识解决问题

基于获取的信息，结合已有经验解决问题。
解决问题时标注参考了知识库中的哪篇文档。

## 可用操作汇总

| 操作 | 用途 | 使用时机 |
|------|------|---------|
| `get_child_pages_by_url` | 获取子页面列表（分类列表/知识页面列表） | 第 2、3 步 |
| `search_pages` | 按关键字直接搜索页面 | 当已知具体关键词时，可替代分类导航快速定位 |
| `query_page_chapter_tree_by_url` | 获取页面块列表 | 第 4 步 |
| `query_block_content_by_url` | 获取块内容 | 第 5 步（按需） |
| `get_page_detail_by_url` | 获取页面详情 | 仅当块信息不足时 |

## 行为准则

### 必须

- ✅ 先获取知识库分类列表，让用户选择分类
- ✅ 再获取分类下的知识页面列表，让用户选择页面
- ✅ 获取页面块结构后，再按需读取相关块内容
- ✅ 解决问题时标注参考了知识库中的哪篇文档
- ✅ 遇到「此操作未授权」时走降级流程（提示用户配置自己的知识库 + `search_pages` 兜底）

### 禁止

- ❌ 不要直接搜索关键词，先通过分类导航
- ❌ 不要一次性读取整个页面或所有块
- ❌ 不要在未了解页面结构前就读取详细内容
- ❌ 不要忽略知识库中的相关经验
- ❌ 对「未授权」的默认知识库页面反复重试（权限问题不会因重试而改变）

## 知识沉淀建议

如果问题解决后发现了新经验或新方法，主动建议用户：

> "这个问题已解决。我建议将这次的成功经验沉淀到知识库，方便以后借鉴。可以用 `/knowledge-save` 触发。"
