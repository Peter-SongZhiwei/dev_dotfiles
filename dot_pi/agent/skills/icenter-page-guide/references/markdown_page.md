# 基于本地 Markdown 文件创建页面（create_page_from_markdown）

## 适用场景

本地已有 Markdown 文件（`.md`/`.markdown`），需要将内容发布为 iCenter 页面。
md→HTML 转换使用 markdown-it-py 在本地完成（commonmark 预设 + 表格/删除线 GFM 扩展），**几乎不消耗 LLM token**。

## 调用方式

```json
execute("create_page_from_markdown", {
  "markdown_file_path": "/path/to/doc.md",   // md 文件绝对路径（必填）
  "parent_id": "父页面ID",                    // 与 parent_url 二选一（必填其一）
  "title": "页面标题",                        // 可选，默认取文件名（不含扩展名）
  "space_id": "空间ID"                        // 可选，parent_id 模式下有效
})
```

或通过父页面 URL：

```json
execute("create_page_from_markdown", {
  "markdown_file_path": "/path/to/doc.md",
  "parent_url": "https://i.zte.com.cn/index/ispace/#/space/{space_id}/wiki/page/{page_id}/view"
})
```

## 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `markdown_file_path` | ✅ | md 文件绝对路径（仅支持 .md/.markdown） |
| `parent_id` / `parent_url` | ✅ 二选一 | 父页面定位，二者不能同时指定 |
| `title` | 可选 | 页面标题，不指定时使用 md 文件名（去扩展名） |
| `space_id` | 可选 | 空间 ID（parent_id 模式有效） |

## 标题原则（重要）

**页面标题由 `title` 字段承载，页面内容（contentBody）中不要重复包含标题：**

- md 内容开头的**第一个一级标题**（`# 文档标题`）会被**自动移除**，不会出现在页面内容中
- `##`/`###` 等二级及以下标题属于章节结构，**原样保留**
- 无需手动在内容中拼接标题文字；标题由 title 参数（或文件名）决定

## Markdown 语法转换支持范围

| 语法 | 支持情况 |
|------|---------|
| 标题、加粗、斜体 | ✅ |
| 行内代码 `` `code` `` | ✅ 自动转换为等宽样式 `<span style="font-family:Consolas,monospace;background-color:#f0f0f0;">`（iCenter 保存时 `<code>` 会被剥离、且列表项内会引起段落拆分，故本地直接转换；2026-10-08 起） |
| 删除线 `~~text~~` | ✅（GFM 扩展） |
| 表格（GFM） | ✅ |
| 有序/无序列表（含嵌套） | ✅ |
| 代码块 | ⚠️ 转换正确（`<pre><code>`），但 **iCenter 平台保存时降级为普通段落**（2026-09-15 实测）。**需要代码样式时必须改用 HTML 通道**：`<pre class="prettyprint linenums brush:xxx">`（JSON 用 `brush:js`）并嵌 `<details>`，见 `references/code_block.md` 与错题本错误 19 |
| 链接 `[text](url)` | ✅（裸 URL 不自动转链接，需用 `[]()` 语法） |
| 分割线 `---` | ✅ |
| 内嵌 HTML | ✅ 原样保留（但 `<pre>`/`<code>` 等被平台降级，见上） |
| 引用 `>` | ⚠️ 转换正确（`<blockquote>`），但 iCenter 平台保存时降级为普通段落，文字不丢失 |
| 任务列表 `- [x]` | ⚠️ 渲染为普通列表项 |

## 注意事项

- **文件编码**：UTF-8 优先，GBK 自动回退，兼容公司内常见编码
- **md 建的页面没有内容块**（2026-10-09 实测：`query_updatable_blocks` 返回 0 个）——整页都是"页面级内容"，
  **不能**用 `update_block_by_url` 局部更新；后续修改用 `update_page_by_url_with_content`（可加 `append_content: true` 追加），
  或从一开始就走"建页 + `create_block_by_url` 分块"的块式写法
- **标题重名**：同名页面自动追加 5 位时间戳后缀（如 `doc_12345`）
- **内容超长**：建议拆分多个 md 文件分别创建，或用 `create_block_by_url` 追加（见 SKILL.md 操作速查表）。**切勿单次提交 ~100KB 级内容**——会让页面进入服务端异常态（detail/chapter-tree/update/delete 全报"页面不存在!"，且 API 删不掉，只能人工在界面删，详见错题本错误 20）；分块时单块 ≤10000 字符，且**切分点不得落在 `<table>`/`<details>` 内部**（否则该表格会被平台整块丢弃）
- 创建成功自动添加 "Generated by AI" 标签（平台行为）
